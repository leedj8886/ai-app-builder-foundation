# AI App Builder Foundation v0.1.0-preview.1 — Build-Verified Foundation

> **Developer Preview / 发布草稿：** 尚未创建 GitHub Release，也尚未将本版本标记为稳定版本。

社区发布时可配合[分平台发布文案与素材清单](v0.1.0-preview.1-launch-kit.md)使用。

这是面向平台建设者的首个公开预览候选版本。项目不是消费级 AI App Builder 的完整替代品，而是帮助开发团队搭建自有 AI App Builder 的开源、自托管平台底座。

本版本使用语义明确、便于 Agent 和 CLI 检索的预发布包标识：

- 根包：`ai-app-builder-foundation@0.1.0-preview.1`
- API 与 Agent Worker：`@ai-app-builder-foundation/server@0.1.0-preview.1`
- Web：`@ai-app-builder-foundation/web@0.1.0-preview.1`

所有包在预发布阶段保持 `private: true`，本版本不向 npm registry 发布。

**不只是生成代码，而是生成能够通过真实构建的代码。**

## 本版本提供什么

- **经过构建验证的生成：** 候选项目依次经过结构校验、依赖准备、TypeScript 检查和生产构建。
- **定向错误恢复：** 代码、依赖和基础设施错误分别进入修复、依赖调整或退避重试路径。
- **可审计 Agent Run：** 异步 Worker 执行，SSE 实时展示持久化事件和验证进度。
- **版本化项目快照：** 经过验证的源码、构建产物和 Branch Head 以 Artifact 与 Snapshot 演进。
- **可替换执行边界：** Model Provider、Validation Executor、ArtifactStore 和 Sandbox Provider 保持独立接口。
- **多模型与应用绑定：** 部署模型目录、Project 默认模型和 Run 级选择保持一致，密钥只进入 Worker 环境。
- **中英文界面：** 支持中文与英文界面切换，并在浏览器中保存语言偏好。
- **工作区导航：** 支持可收起、边缘预览和固定展开的对话侧边栏。
- **自托管平台骨架：** React、Express、MongoDB、Redis、BullMQ、Nginx 和 Docker Compose。

## 推荐演示

使用一个包含图表和筛选器的运营 Dashboard，展示以下完整路径：

`提示词 → 规划 → 生成 → 真实构建 → 诊断失败 → 定向修复 → 验证后快照`

演示必须来自当前版本的真实行为，不应隐藏安装步骤或暗示所有提示词都会成功。

社区预热可使用仓库内的[首图与 24 秒确定性产品导览](../community-demo.md)，展示模型选择、可审计 Run、构建验证后的代码与 Preview，以及尚未配置的导出边界。另有一段[30 秒真实 DeepSeek 失败恢复演示](../assets/community-preview/recovery-demo.mp4)：录制环境明确注入一个 TypeScript 类型错误，`deepseek-v4-flash` 根据真实验证诊断完成一次修复，随后 TypeScript 检查与生产构建通过并生成快照。该演示全程披露受控故障注入，不应描述为模型自然失败或安全审计证明。

## 当前限制

- `AI App Builder Foundation` 是当前统一品牌，正式商标与域名检查仍需在稳定版前完成。
- 尚未提供公开在线 Demo 和一键云部署。
- Daytona 当前用于临时 Build Sandbox；长驻 PreviewDeployment 尚未实现。
- 构建通过不代表生成代码已经通过业务、安全、隐私或合规审计。
- `npm run lint` 已覆盖 Server 和 Web 的 TypeScript 基线并纳入 CI。
- 全量依赖已完成升级；`npm run audit:dependencies` 只放行 React Router RSC Mode 公告。
  当前项目只使用客户端路由，临时风险接受及退出条件见
  [依赖审计处置](../security/audit-v0.1.0-preview.1.md)。
- 封闭的 Docker Smoke 已通过并作为 required check，覆盖 API、浏览器生成、快照恢复
  和 verified Preview。历史 Snapshot 的 Sandpack Source Preview 依赖 CodeSandbox 与
  jsDelivr，已拆为非阻塞定时监控，不影响核心自托管门禁。

## 发布前验证

创建 GitHub Preview Release 前，应重新运行：

```bash
npm run test:readiness
npm run test --workspace @ai-app-builder-foundation/server
npm run test --workspace @ai-app-builder-foundation/web
npm run build
docker compose --env-file .env.example config --quiet
npm run audit:dependencies
npm run test:smoke
```

需要同时检查外部 Sandpack 服务时，另行运行 `npm run test:smoke:external`。

## 升级与数据说明

从早期开发数据库升级时，应先停止 API Server 和 Worker、备份 MongoDB，再按 README 执行 Workspace/Branch 迁移。新安装不需要迁移。

ArtifactStore 中的 Snapshot 与 Preview Build 不保存在 MongoDB；部署时必须确保 API Server、Worker 和维护任务共享同一个 ArtifactStore。

## 稳定版 `v0.1.0` 门槛

- 完成正式商标与域名检查。
- 保持 lint 基线与持续集成全绿。
- 移除 React Router 临时风险接受，或在稳定版安全评审中重新批准。
- 持续保持完整 Docker Smoke 通过。
- 至少五名未参与开发的测试者只使用公开文档完成安装；至少四人在十分钟内启动。
- 每名成功测试者完成一次真实生成和一次后续修改。
- 发布可复现的 20–30 秒失败恢复演示。
- GitHub description、topics、social preview 和 Release Notes 完整。

满足以上条件后，再将本草稿整理为稳定版本：
